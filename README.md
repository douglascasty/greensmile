# Green Smile - Website Oficial

Website oficial da clínica odontológica **Green Smile** (Jabaquara - São Paulo).

## 🚀 Como Iniciar o Projeto

### Opção 1: Atalho Windows (.bat)
Dê um duplo clique no arquivo **[start.bat](file:///c:/Users/dougl/Downloads/green-smile-base44-clone/start.bat)**. O servidor local será iniciado e o navegador abrirá automaticamente a página do site.

### Opção 2: Script Python (.py)
Execute o arquivo **[start.py](file:///c:/Users/dougl/Downloads/green-smile-base44-clone/start.py)** no terminal ou com duplo clique:
```bash
python start.py
```

### Opção 3: Via Terminal (NPM)
```bash
npm install
npm run dev
```

## 🛠️ Tecnologias Utilizadas
- **React 18**
- **Vite**
- **Tailwind CSS**
- **Lucide Icons**
- **Framer Motion**
